Robust and Efficient Monocular 3D Gaussian SLAM for Kilometer-Scale Outdoor Scenes

Sicheng Yu*, Dongxu Shen*, Beizheng Zhao, Guanzhi Ding, Hao Wang†

Accepted by ECCV

Existing monocular 3D Gaussian Splatting SLAM systems struggle with long outdoor trajectories: pose tracking drifts, memory grows quickly, and densification is hard to keep consistent across views. KiloGS-SLAM targets kilometer-scale outdoor reconstruction under these constraints.

The framework introduces an image-texture-complexity-aware Gaussian initialization strategy, together with multi-view-consistency-guided densification and pruning. These components improve tracking robustness and control memory overhead for long-sequence outdoor scenes.
